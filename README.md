# Healthcare Claims App

A full-stack web application designed to help users view healthcare claims, understand their healthcare costs, and manage notes associated with their claims.

> **Status:** In Development

## Features

* View healthcare claims for individual users
* View detailed claim information
* View a breakdown of billed amounts, insurance payments, and patient responsibility
* Generate user-friendly, rules-based explanations of claim costs
* Add, edit, and delete notes associated with claims

## Tech Stack

* Next.js
* TypeScript
* React
* PostgreSQL
* Drizzle ORM
* Tailwind CSS

## API

The application includes REST API endpoints for:

* Retrieving users and claims
* Retrieving individual claim details
* Creating, updating, and deleting claim notes
